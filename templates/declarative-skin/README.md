# __THEME_NAME__

1. 将 Light/Dark 背景保存为 `assets/backdrop-light.webp` 与 `assets/backdrop-dark.webp`。
2. 将安全装饰素材保存为 `assets/mark-light.webp` 与 `assets/mark-dark.webp`。
3. 在 `theme.json` 中编辑 Token、背景和 Theme Parts v2 外观。
4. 在 `visuals.json` 中选择固定模板与安全语义槽位；不支持 JavaScript、HTML、任意 CSS 或外部 URL。
5. 在插件目录执行 `pnpm skin:pack <此主题目录>`。

可用模板为 `image-mark`、`compact-brand` 与 `status-chip`。功能性图标不可替换。
